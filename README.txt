GhostDraft v1
Open index.html in a desktop browser for a local trial. For Android and installable offline use, host all files together on HTTPS (e.g. GitHub Pages). Create a public repository, upload the contents of this folder at its root, then Settings > Pages > Deploy from a branch > main / root > Save. Open the published URL in Android Chrome and use its menu to install/add to home screen. On Windows use Chrome or Edge. Visit online once before testing offline. Drafts are stored in the browser on each device, not in the repository. Export backups regularly; clearing site data can erase drafts. No automatic sync. Sprint statistics count net words, not keystrokes. Active sprint is not restored after closing. Ghost mode is a visual aid, not encryption. Android keyboard and installation behavior require real-device testing.
